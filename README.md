# alba

A chess engine built from the ground up in C as a learning project.

The main purpose of this project is to understand how chess engines are built internally, from board representation and move generation to search and evaluation.

## Acknowledgements

This project will be built in public while primarily following [ABC — A Chess Programming Book](https://github.com/maksimKorzh/abc) by Maksim Korzh as the main learning resource and reference implementation. The accompanying textbook is available online at [ABC — An Online Chess Programming Book](https://maksimkorzh.github.io/abc/).
